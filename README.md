# MSQ Studio

> 중요: 첨부된 모든 파일과 폴더 이름은 변경하지 마세요.

MSQ Studio는 스타크래프트 EUD 음악 퀴즈 유즈맵을 쉽고 안정적으로 제작하기 위한 올인원 제작 도구입니다.

노래 추가, 맵 설정, 음원 자르기, 챗 이벤트 생성, 빌드, 디버그까지 대부분의 제작 과정을 GUI로 관리할 수 있습니다.

---

## 기본 정보

* 프로그램 이름: MSQ Studio
* 용도: StarCraft 음악 퀴즈 맵 제작 도구
* 제작자: eeee

## 처음 시작하기 전에 꼭 읽어주세요

MSQ Studio는 여러 파일과 폴더가 서로 연결되어 동작합니다.

따라서 아래 내용은 반드시 지켜 주세요.

* 첨부된 파일 이름을 변경하지 마세요.
* 첨부된 폴더 이름을 변경하지 마세요.
* 프로그램 폴더 구조를 임의로 바꾸지 마세요.
* `Setting.py`는 노래 데이터의 핵심 파일입니다.
* `res`, `sound`, `SFX` 폴더는 기능별로 사용되는 중요 폴더입니다.
* 빌드나 컴파일 중에는 관련 파일을 외부 편집기로 동시에 수정하지 않는 것을 권장합니다.

## 추천 작업 흐름 상세

### 1단계. 맵 설정

먼저 게임 전체 규칙을 정합니다.

예시:

* 주제 / 노래 / 가수 / 주관식 / 객관식 사용 여부
* 힌트 출력 시간
* 2차 힌트 사용 여부
* 오프닝 / 엔딩 시간
* 정답 공개 여부
* UI 방식
* 스킵 키
* 점수
* 효과음
* 연결된 맵 / 저장 맵

맵 설정을 먼저 해두면 노래 추가 화면에서 사용하지 않는 항목이 자동으로 비활성화되어 입력 실수를 줄일 수 있습니다.

### 2단계. 오프닝 / 엔딩 설정

게임 시작과 종료 시 표시할 문구를 설정합니다.

* 오프닝 멘트 1~3 설정
* 엔딩 멘트 설정
* 스타크래프트 색상 / 정렬 제어문자 지원
* 실제 인게임 출력 기준 미리보기
* 최대 줄 수 제한 적용

### 3단계. 음원 자르기

게임에 사용할 음원을 준비합니다.

* 유튜브 / 니코동 / 비리비리 링크 사용 가능
* 로컬 음원 / 일부 영상 파일 사용 가능
* MP3 / OGG / WAV 출력 지원
* 오프닝, 엔딩, 문제곡 구간 자르기
* 맵 삽입용 분할 음원 자동 생성
* 음원 정보 검사
* 자른 음원 검사
* 누락 재자르기
* 불필요 파일 정리

주의:

* 0번 행은 오프닝입니다.
* 1번 행은 엔딩입니다.
* 2번 행부터 실제 문제곡입니다.
* 링크나 파일을 표에 넣은 뒤 반드시 자르기를 실행해야 실제 파일이 생성됩니다.

### 4단계. 노래 추가

문제로 사용할 곡 정보를 등록합니다.

* 제목 / 노래 / 가수 입력
* 힌트 / 2차힌트 입력
* 주관식 / 객관식 문제 입력
* 기존 데이터 기반 자동완성
* 힌트 일괄 생성
* 2차힌트 일괄 생성
* 입력값 검사
* 저장 후 Setting.py / Setting.txt 반영

주의:

* 맵 설정에서 꺼둔 항목은 노래 추가 화면에서도 비활성화됩니다.
* 가수와 주관식 정답은 중간을 비우지 말고 앞에서부터 연속으로 입력해야 합니다.
* 힌트는 일반 한글보다 초성 / 숫자 / 영문 / 기호 중심으로 입력합니다.

### 5단계. 빌드

설정한 데이터와 음원을 바탕으로 빌드를 실행합니다.

빌드 과정에서는 다음 작업이 진행됩니다.

* 설정 데이터 파싱
* 음원 삽입 준비
* 챗 이벤트 데이터 준비
* 맵 빌드 준비
* EUD3 컴파일에 필요한 파일 구성

빌드 중 오류가 발생하면 로그를 확인해서 어떤 데이터에서 문제가 났는지 먼저 확인하세요.

### 6단계. 챗 이벤트

빌드 후 생성되는 챗 정답 이벤트를 관리합니다.

* 기본정답 / 추가정답 관리
* 중복 정답 사용 가능
* 중복 정답 표시
* 검색
* 복사 / 붙여넣기
* Undo / Redo
* 열 추가 / 삭제
* 백업
* 백업에서 추가정답 자동복사
* 챗 이벤트 파일 생성

주의:

* 중복 표시는 오류가 아니라 같은 답안이 여러 곳에서 사용 중이라는 확인 표시입니다.
* 챗 이벤트를 수정한 뒤에는 챗 이벤트 파일 생성을 다시 해야 합니다.

### 7단계. 디버그

맵을 실행하지 않고도 정답과 힌트 상태를 확인합니다.

* 정답 / 힌트 / 2차힌트 확인
* 주관식 / 객관식 확인
* 챗이벤트 미리보기
* 인게임 프리뷰
* 정답 인식 확인
* 음원 재생
* 텍스트 직접 수정

주의:

* 챗 이벤트 미리보기가 이상하면 챗 이벤트 파일을 다시 생성한 뒤 확인하세요.

### 8단계. 최종 컴파일 / 테스트

빌드와 챗 이벤트 확인이 끝나면 최종 컴파일과 실제 테스트를 진행합니다.

테스트할 때는 다음을 확인하세요.

* 오프닝 / 엔딩 출력
* 음원 재생
* 힌트 출력 시간
* 정답 인식
* 주관식 / 객관식 동작
* 스킵 키
* 효과음
* 점수
* 리더보드

## 1. 맵 설정

노래 맞히기 맵의 핵심 옵션을 설정합니다.

### 주요 설정

* 스피드 모드 힌트 출력 시간
* 감상 모드 힌트 출력 시간
* 주관식 힌트 출력 시간
* 2차 힌트 출력 시간
* 오프닝 / 엔딩 시간
* 주제 / 노래 / 가수 사용 여부
* 주관식 / 객관식 사용 여부
* 기본 UI / 디자인 UI 선택
* 자동다음곡
* 정답공개
* 랭킹 / 익명
* 스킵 키
* 문항 이름 / 색상 / 점수
* 맵 이름 / 설명 / 포스 이름
* 효과음
* 연결된 맵 / 저장 맵

### 주의사항

* 객관식은 기본 UI에서만 사용할 수 있습니다.
* 디자인 UI를 사용하면 객관식은 사용할 수 없습니다.
* 주제 / 노래 / 가수 / 주관식 / 객관식 중 최소 하나는 켜져 있어야 합니다.
* 효과음은 SFX 폴더 안의 wav / ogg 파일만 사용할 수 있습니다.
* 연결된 맵과 저장 맵은 scx 파일이어야 합니다.

게임 시작 및 종료 시 출력되는 문구를 편집하고 미리 확인하는 기능입니다.

### 주요 기능

* 엔딩 멘트 설정
* 스타크래프트 제어문자 기반 색상 / 정렬 지원

## 3. 노래 추가

노래 맞히기에 사용될 문제 데이터를 등록합니다.

### 주요 기능

* 제목 / 노래명 / 가수 입력
* 가수 최대 15명 입력
* 제목 추가 세트 최대 3개 입력
* 주관식 정답 최대 20개 입력
* 객관식 4지선다 입력
* 힌트 / 2차힌트 입력
* 힌트 일괄 생성
* 2차힌트 일괄 생성
* 자동완성 지원
* 입력값 검사
* 추가 전 확인창
* 저장 후 설정 파일 자동 반영

### 주의사항

* 가수는 1번부터 중간에 빈칸 없이 입력해야 합니다.
* 주관식 정답도 1번부터 중간에 빈칸 없이 입력해야 합니다.
* 정답과 힌트는 한 세트입니다.
* 힌트에는 일반 한글보다 초성 / 숫자 / 영문 / 기호를 사용합니다.

## 4. 노래 수정 / 노래 리스트

이미 추가된 노래를 번호 또는 리스트 기준으로 관리합니다.

### 노래 수정 화면

* 노래 번호 입력 후 수정 열기
* 두 번호의 곡 순서 변경
* 특정 곡 삭제
* 전체 삭제
* 미리보기로 대상 확인
* 노래 리스트 열기

### 노래 리스트 화면

* 전체 곡 목록 확인
* 검색
* 번호 여러 개 검색
* 중복만 보기
* 공백 / 특수문자 무시 검색
* 정확히 일치 검색
* 열 정렬
* 더블클릭 / Enter로 수정 열기
* Delete / 우클릭으로 삭제
* 여러 곡 삭제
* 단일 선택 드래그로 순서 이동
* Setting.py 변경 자동 감지

### 주의사항

* 삭제와 전체 삭제는 되돌리기 어렵습니다.
* 드래그 순서 이동은 단일 선택일 때만 가능합니다.
* 중요한 작업 전에는 백업을 권장합니다.

## 6. 장르 설정

노래를 장르 단위로 묶기 위한 설정 화면입니다.

### 주요 기능

* 장르 개수 설정
* 장르 이름 설정
* 장르별 곡 개수 지정
* 설정 저장 및 재사용
* 빌드 시 장르 정보 반영

### 중요 주의사항

장르 설정에서 정한 순서대로 노래를 추가해야 합니다.

예시:

* 애니메이션 20곡
* JPOP 20곡
* KPOP 20곡

위처럼 설정했다면 다음 순서로 노래가 들어가야 합니다.

1. 애니메이션
2. JPOP
3. KPOP

이 순서가 맞지 않으면 장르 분류가 정상적으로 동작하지 않습니다.

### 주의사항

### 주요 기능

* 기본정답 / 추가정답 입력
* 같은 의미의 답안을 한 줄에 묶기
* 중복 정답 사용 가능
* 중복 정답 표시
* 검색
* 복사 / 붙여넣기
* 다중 셀 붙여넣기
* 실행 취소 / 다시 실행
* 열 추가 / 삭제
* 열너비 자동맞춤
* 백업
* 백업에서 추가정답 자동복사
* 챗 이벤트 파일 생성

### 주의사항

* 한 칸은 최대 26자까지 입력 가능합니다.
* 중복 표시는 오류가 아니라 확인 표시입니다.
* 백업 자동복사는 기본정답이 같은 행의 추가정답을 복사합니다.

## 12. 노래 검색 / 불러오기

유튜브를 기반으로 노래를 검색하고 바로 재생할 수 있는 기능입니다.

검색한 결과를 음원 자르기 기능의 음원정보와 연동하여 제작에 바로 활용할 수 있습니다.

### 기본 기능

* 노래 제목 또는 가수명으로 검색
* 검색 정렬 방식 선택
* 검색 결과 클릭 시 즉시 재생
* 음원정보에서 불러온 경우 재생 구간 자동 적용
* 유튜브 재생목록 불러오기

검색 정렬 방식:

* 관련도순
* 조회수순
* 최신순

주의:

검색 정렬은 유튜브 알고리즘이 그대로 적용되는 것이 아니므로 원하는 결과가 항상 나오지는 않을 수 있습니다.

### 재생 기능

* 유튜브 영상 직접 재생
* 재생 / 일시정지
* 이전 곡 / 다음 곡
* 5초 단위 이동
* 볼륨 조절
* 음소거
* 현재 재생 시간 표시
* 구간 반복
* 자동 다음 곡

### 음원정보 연동

검색 결과 우클릭 메뉴에서 다음 작업을 할 수 있습니다.

* 유튜브 링크 열기
* 제목 복사
* 링크 복사
* 음원정보에 링크 삽입
* 음원정보 불러오기
* 유튜브 재생목록 불러오기

여러 곡 선택 시 다중 삽입도 지원합니다.

삽입 시 기본 재생 구간은 다음처럼 설정됩니다.

* 시작: 0:30
* 종료: 1:50

### 유튜브 재생목록 불러오기

유튜브 재생목록 링크를 입력하여 재생목록에 포함된 곡을 한 번에 불러올 수 있습니다.

지원:

* 공개 재생목록
* 일부 공개 재생목록

지원하지 않음:

* 비공개 재생목록

### 재생목록에서 일부 영상이 누락될 수 있는 경우

아래 조건에 해당하는 영상은 오류 없이 자동으로 건너뛰어질 수 있습니다.

* 국가 제한으로 재생이 차단된 영상
* 비공개 또는 삭제된 영상
* 연령 제한 등으로 API 접근이 불가능한 영상
* YouTube API에서 정보 조회가 실패한 영상
* 길이가 너무 짧거나 너무 긴 영상

위 사유에 해당하는 영상은 정상적으로 재생하거나 정보를 불러올 수 없기 때문에 자동으로 제외됩니다.
